# Portfolio Lucas

Portfólio profissional desenvolvido com Next.js, TypeScript, Tailwind CSS, shadcn/ui (Base UI), Motion e Lucide Icons.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui com Base UI
- Motion
- Lucide React
- ESLint

## Requisitos

- Node.js 20.9 ou superior
- npm

## Ambiente local

```bash
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:3000`.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
